# Hydropower in the Headlines

Reproducibility materials for:

**Hydropower in the Headlines: A Media Discourse Model for Tracking Emotional Orientations towards Hydropower in Europe**

## Overview

This repository contains the code and legally shareable derived data used for the analysis presented in the paper.

The study develops a Media Emotion Index (MEI) to examine changes in the emotional orientation of media discourse surrounding two established pumped-storage hydropower facilities:

- Alqueva, Portugal
- Le Cheylas, France

The final corpus contains 646 articles covering the period 2018–2025.

The MEI measures the emotional orientation of media discourse surrounding hydropower infrastructure over time. It is not a direct measure of public opinion or social acceptance.

## Repository contents

- `01_reproduce_analysis.R` — reproduces the article-level MEI, monthly aggregation, equal-weight robustness analysis, weight perturbation analysis, and native-language polarity comparison.
- `SEARCH_QUERIES.md` — documents the MediaCloud search strategy used to construct the corpus.
- `data/` — contains the legally shareable derived data required by the analysis.
- `results/` — contains outputs generated by the analysis script.
- `figures/` — reserved for figures associated with the analysis.

## Data availability

The underlying news articles and translated article text are not redistributed where copyright or source restrictions prevent this.

The repository therefore provides legally shareable derived data rather than the full article corpus.

The English translations used for the NRC emotion analysis were generated before publication using the Google Cloud Translation API. The translation step is not rerun by the reproducibility script and no API credentials are required.

## Reproduction

1. Download or clone this repository.
2. Open `01_reproduce_analysis.R` in R/RStudio.
3. Set the working directory to the repository root.
4. Ensure the required R packages are installed.
5. Run the script.

The script generates the analytical outputs in the `results/` folder.

## Search strategy

The MediaCloud search strategy is documented in `SEARCH_QUERIES.md`.

The exact MediaCloud query used for Le Cheylas is provided. For Alqueva, the archived project materials retain the search vocabulary but not the exact original Boolean query string.
